# Kapadiya Shreyas M. — Portfolio

A responsive dark-theme portfolio for AI Engineering, Machine Learning, and Generative AI opportunities. Built with React, Vite, Lucide icons, custom CSS, and lightweight scroll-triggered animations.

## Run locally

Requirements: Node.js 18+ recommended.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/` and can be deployed to static hosting such as Vercel, Netlify, or GitHub Pages (with base-path configuration if needed).

## Content notes

- Profile, education, experience, skills, and project descriptions are based on the supplied resume.
- Only the Hospital Management System has a project repository link in the resume, so other project cards do not invent links.
- No certifications, numerical project results, or unsupported achievements have been added.
- Contact details and LinkedIn/GitHub links are included as provided in the resume.

## Before publishing

1. Run `npm install` and `npm run build` to verify the production build.
2. Confirm all public contact details and profile links are correct.
3. Add a resume PDF download only after placing the intended, current resume file in `public/`.
4. Add live demos or additional repository links when available.
